# StudyAI Guidelines

This is the standalone **studyAI** implementation of the AI-Powered Study Material Recommender for IGNOU BCSP-064 (Shubham Kumari, 2400625700).

- **Framework**: TanStack Start (React 19 + Nitro SSR)
- **Database**: PostgreSQL on Supabase
- **Recommendation**: Dual-model TF-IDF + Collaborative Filtering engine
- **Search**: Server-side full-text database query with pagination
- **Reports**: 5 mandatory Section 5.6 admin analytics reports
